# Практична робота №4 — LINQ to Objects та асинхронне програмування (C#, .NET 10)

**Варіант 1. Порівняння цін в інтернет-магазинах.** Виконав: Івонік Максим, група 3ПІ-24б.

- 3 асинхронні джерела (`ТехноМаркет`, `ЦифраПлюс`, `Електросвіт`) з різними затримками `Task.Delay`, 25 пропозицій.
- Паралельне (`Task.WhenAll`) і послідовне завантаження з вимірюванням часу `Stopwatch` (≈2,0 с проти ≈4,5 с).
- LINQ: найдешевша пропозиція (`GroupBy`, `Any`, `MinBy`), статистика за категоріями, пошук у діапазоні цін (синтаксис запиту), список бажань (`Join`), товари в усіх магазинах (`All`).
- Асинхронне збереження звіту в JSON із читабельною кирилицею та обробкою `IOException`.

## Запуск
```
dotnet run
```
або відкрити `Prices.sln` у Visual Studio і натиснути F5.
